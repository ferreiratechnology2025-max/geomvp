# GEO Auditor — Visibilidade em Motores de IA

Diagnóstico automatizado para Generative Engine Optimization (GEO).

## Funcionalidades
- Analise de 12 sinais tecnicos
- Matriz comparativa com concorrentes
- Plano de acao priorizado
- Geracao automatica de JSON-LD
- Relatorio HTML/PDF profissional

## Deploy Local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Modo Demo
Selecione "Modo Demo" na interface para testar sem API key.
